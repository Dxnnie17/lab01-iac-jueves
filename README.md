# Lab01 - Despliegue de Dos Páginas Web con Docker

Bienvenido al laboratorio. Este proyecto te enseña a **desplegar dos páginas web diferentes** usando **Docker** de forma fácil y ordenada.

Vamos a crear dos sitios web simples:
- **Web01** → Se verá en http://localhost:4000
- **Web02** → Se verá en http://localhost:4001


ve a:
- **Web01** → http://localhost:4000
- **Web02** → http://localhost:4001

## Puertos

- **Puerto 4000** → Web01 (primer sitio)
- **Puerto 4001** → Web02 (segundo sitio)
